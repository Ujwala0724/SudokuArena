# SudokuArena
Developed a full-stack web application that provides an interactive Sudoku gaming experience with four difficulty levels: Easy, Medium, Hard and Expert.

Key Features:

Implemented dynamic Sudoku puzzle generation using randomized backtracking algorithms.

Built an interactive puzzle board with number entry, notes, undo, erase, hints, timer, pause and reset functionalities.

Developed secure user registration and login with salted PBKDF2 password hashing.

Implemented server-side puzzle validation, scoring, accuracy calculation and game result tracking.

Designed player dashboards to track games played, wins, losses, points, experience points (XP), levels and winning streaks.

Created a friends system using unique invite codes and a leaderboard for comparing player performance.

Developed an administrator dashboard with user search and account activation/deactivation features.

Implemented session-based authentication and role-based access control to protect player and administrator modules.

Technologies Used: Java, Java Servlets, JSP, JSTL, JDBC, Oracle SQL, HTML, CSS, JavaScript, Apache Tomcat, Maven.
